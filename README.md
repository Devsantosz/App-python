### 💳 Sistema Bancário Simples em Python (POO)

Este projeto é uma aplicação simples desenvolvida em Python, com foco em Programação Orientada a Objetos (POO).
O sistema simula operações bancárias básicas utilizando classes para representar Cliente e Conta.

## 🚀 Funcionalidades

<ul>
  <li>👤 Cadastro de cliente</li>
  <li>💰 Depósito em conta</li>
  <li>🏧 Saque com verificação de saldo</li>
  <li>📄 Consulta de extrato</li>
  <li>🔒 Validação para impedir saldo negativo</li>
  <li>🧠 Uso de encapsulamento com @property</li>
</ul>

## 🛠️ Tecnologias Utilizadas

<ul>
  <li>Python 3</li>
  <li>Programação Orientada a Objetos (POO)</li>
</ul>

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com fins educacionais para praticar:

<ul>
  <li>Criação e organização de classes</li>
  <li>Encapsulamento com @property</li>
  <li>Métodos de instância</li>
  <li>Separação de responsabilidades</li>
  <li>Estruturação de pequenos sistemas em Python</li>
</ul>
